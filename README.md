# SimpleCloud Kubernetes (archived prototype)

> [!WARNING]
> This repository contains an abandoned, unreleased Kubernetes prototype. It is not the current version of SimpleCloud and should not be used for new installations. Current SimpleCloud does not require Kubernetes.

## Current SimpleCloud

SimpleCloud is a Minecraft server management platform for running networks across one or more machines. It provides a dashboard and CLI, server groups with automatic scaling, templates, and persistent servers.

- [Website](https://simplecloud.app/)
- [Documentation](https://simplecloud.app/docs)
- [Current GitHub repository](https://github.com/simplecloudapp/simplecloud)
- [Dashboard](https://dash.simplecloud.app/)

## About this repository

This codebase explored a Kubernetes-based architecture for a possible SimpleCloud v3. Development stopped before the project became usable, and it was never released as the supported SimpleCloud v3 product.

The Kubernetes requirements, planned dashboard, modules, and architectural claims in this repository apply only to this prototype. They do not describe the current SimpleCloud product. The repository remains available as a historical archive.
